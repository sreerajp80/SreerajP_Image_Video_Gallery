# Plan — Rename the app to "Drishya Gallery"

**Status:** completed

**Date:** 2026-11-08

## The issue

The app is called "SreerajP Image Video Gallery". That name is long, gets cut off under the icon,
and is hard to find by typing in the launcher search. The owner picked a new name:

| Where | English | Malayalam | Sanskrit |
|---|---|---|---|
| Under the icon (prod) | Drishya Gallery | ദൃശ്യ | दृश्य |
| Under the icon (dev) | Drishya Gallery Dev | ദൃശ്യ Dev | दृश्य Dev |
| Title inside the app, About screen | Drishya Gallery | ദൃശ്യ | दृश्य |
| Play Store app name (limit 30) | Drishya: Photo & Video Gallery (en-IN) | ദൃശ്യ: ഫോട്ടോ & വീഡിയോ ഗാലറി (ml-IN) | — (Sanskrit is not a Play listing language) |

Note: the request said "Drishya Galler". This plan reads it as **Drishya Gallery**.

Why the name inside the app is the same as under the icon: `test/android/launcher_name_test.dart`
requires the prod launcher name to equal `appName` in `assets/config/app_config.json` for every
language (guideline.md §1.8). Keeping one name per language also stays simple.

## What does NOT change

- Package / application id `in.sreerajp.imgvidgal` (and `.dev`). Play does not allow changing it.
- Dart package name `in_sreerajp_imgvidgal`, keystore, signing, alias.
- The GitHub repository name and the privacy policy URL (both stay as they are, so the link
  already given to Play keeps working).
- The app icon.
- Old plans and change logs in `plans/` and `change_log/`. They are history.
- Point-in-time documents `docs/implementation_plan.md` and
  `docs/feature_improvements_and_standout_features.md`. They record what was true when written.
- The `docs/guidelines/` submodule (read-only).
- The version number. The next release bumps it as usual (release_process.md).

The default-app dialog uses the name the phone shows in Android's "Open with" list. That list
shows the launcher name in the phone's language, so each language uses its own launcher name.

No new ARB keys. No test changes are expected: the launcher-name test reads both files, and the
other tests use their own made-up names. If any test does fail, I will fix it and say so in the
change log.
