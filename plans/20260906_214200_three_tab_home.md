# Three-Tab Home Screen with Unified Functionality

**Status:** Approved

## Issue

The Timeline screen has multi-select, batch actions (11 total), flashbacks, pinch-to-zoom, and fast-scroll. The Albums and Folders screens have none of these features. Users also cannot easily access Camera folder images without going through Timeline → Albums → Folders section → Camera.

## Fix

Replace the single-screen home with a three-tab scaffold using `NavigationBar`:

1. **Timeline tab** — media grouped by date (existing functionality)
2. **Folders tab** — device folders list, tapping opens folder media grid
3. **Albums tab** — user-made + smart albums, tapping opens album media grid

All tabs and their sub-screens share the same selection and batch-action system.
