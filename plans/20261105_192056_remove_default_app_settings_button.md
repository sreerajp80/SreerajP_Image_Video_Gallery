# Remove the "Open Android Settings" button from the Default Gallery screen

**Status:** completed

## The issue

Settings → Default Gallery App shows an "Open Android Settings" button. It opens
Android's "Default apps" page (`ACTION_MANAGE_DEFAULT_APPS_SETTINGS`). That page only
lists fixed roles (browser, phone, SMS, home screen, assistant). Android has no
"gallery" role, so the user can never set this app as the default gallery there.
The fallback pages ("Open by default" for this app, App info) do not help either:
"Open by default" covers web links only.

The only real way is the "Open with" chooser plus "Always". The screen text already
explains that. The button misleads the user, so it goes away.

The last line of the instruction text ("You can also configure defaults in Android
Settings.") is also misleading. It is replaced with a true and useful hint: if
another app already opens photos, clear that app's default first.

## New last line of `bodyDefaultAppDialog`

- **en:** "If another app already opens your photos, first clear its default: Android Settings → Apps → that app → Open by default."
- **ml:** "മറ്റൊരു ആപ്പ് ഇപ്പോൾ ഫോട്ടോകൾ തുറക്കുന്നുണ്ടെങ്കിൽ, ആദ്യം അതിന്റെ ഡിഫോൾട്ട് മാറ്റുക: ആൻഡ്രോയിഡ് സെറ്റിംഗ്സ് → Apps → ആ ആപ്പ് → Open by default."
- **sa:** "यदि अन्यः अनुप्रयोगः इदानीं चित्राणि उद्घाटयति, तर्हि प्रथमं तस्य पूर्वनिर्धारणं निष्कास्यताम्: Android विन्यासः → Apps → सः अनुप्रयोगः → Open by default।"

Menu names ("Apps", "Open by default") stay in English because that is how they show
in Android on most phones. **The Sanskrit line needs the owner's review** (CLAUDE.md
localization rules).
