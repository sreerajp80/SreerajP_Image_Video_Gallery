# Shorter Malayalam labels for the batch action bar

**Status:** completed

## Issue

The Malayalam labels on the selection action bar are long. They wrap to two lines and get
cut off (for example "ഒരു ഉപകരണത്തിലേക്ക് അയയ്..."). The owner gave shorter wording.

## Files to change

- `lib/l10n/app_ml.arb` — five values only.
- `lib/l10n/generated/app_localizations_ml.dart` — regenerated by `flutter gen-l10n`, not hand-edited.

No English or Sanskrit text changes. No new keys.

## Fix

| Key | Old | New |
|-----|-----|-----|
| `bodyBatchActionTransfer` | ഒരു ഉപകരണത്തിലേക്ക് അയയ്ക്കുക | ഉപകരണത്തിലേക്ക് അയക്കുക |
| `labelBatchActionFavourite` | പ്രിയപ്പെട്ടവയിൽ ചേർക്കുക | പ്രിയപ്പെട്ടതാക്കുക |
| `labelBatchActionAddToAlbum` | ആൽബത്തിൽ ചേർക്കുക | ആൽബത്തിലാക്കുക |
| `titleBatchActionMoveToTrash` | ചവറ്റുകുട്ടയിലേക്ക് മാറ്റുക | കളയുക |
| `bodyBatchActionUnfavourite` | പ്രിയപ്പെട്ടവയിൽ നിന്ന് നീക്കുക | പ്രിയപ്പെട്ടതല്ലാതാക്കുക |

Then run `flutter gen-l10n`, `flutter analyze` and `flutter test`.

## Side effects to know

`titleBatchActionMoveToTrash` is also used in the photo viewer: the bottom bar button, the
top-bar menu item, and the confirm button of the "move to trash" dialog
(`lib/widgets/viewer/viewer_dialogs.dart`). All of these will show "കളയുക" too.
The screen `titleAlbumPicker` ("ആൽബത്തിൽ ചേർക്കുക") is a different key and stays as it is.

## Security impact

None. Text change only.
