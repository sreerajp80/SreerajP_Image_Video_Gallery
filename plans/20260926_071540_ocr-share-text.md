## The issue

`ExtractedTextScreen` (`lib/screens/ocr/extracted_text_screen.dart`) lets the user select
text, **Copy all**, and **Save to notes**. There is no way to send the text straight to
another app (a notes app, a messenger, a translator). The user has to copy, switch apps, and
paste.

## The fix

Use Android's own share sheet (`ACTION_SEND` with `text/plain`). The app already has a native
share path for files on the `in.sreerajp.imgvidgal/intents` channel. We add a text version
next to it. **No new package.**

### Native side (Kotlin)

In `IntentChannelHandler.kt`, add a `shareText` method:

- It reads `text` from the call. It rejects an empty text or a text longer than a set limit
  (see below) with `result.success(false)`.
- It builds `Intent(Intent.ACTION_SEND)` with type `text/plain` and `EXTRA_TEXT`, wrapped in
  `Intent.createChooser(...)` with a localised title passed from Dart.
- It catches `ActivityNotFoundException` and any other exception and returns `false`. It
  never crashes (hard rule 5).
- Nothing is logged except "share text: started / failed", never the text.

### Dart side

- `IntentChannel.shareText(String text, {required String title})` in
  `lib/services/scan/intent_channel.dart`, returning `Future<bool>`. It uses the existing
  `_invoke` helper, which already handles channel errors.
- `ScanActionRunner.share(...)` in `lib/providers/scan_providers.dart`, next to `copy`.
- A **Share** button on `ExtractedTextScreen`, in the bottom bar between "Save to notes" and
  "Copy all". To keep the bar from overflowing on narrow phones and in Malayalam, "Save to
  notes" and "Share" become icon buttons with localised tooltips, and "Copy all" stays the
  main labelled button.
- If the user has selected part of the text, Share sends only that part; otherwise it sends
  all of it. If tracking the selection turns out messy, we fall back to "always all" and say
  so in the change log.
- On failure, show a short snackbar ("Could not share").

### Length limit

Android drops intents larger than about 1 MB. Add `AppConstants.shareTextMaxLength` (for
example 100,000 characters) and check it in both Dart and Kotlin. OCR text is far below this
in practice.

### Privacy

Sharing happens only when the user taps Share and picks a target app in Android's own sheet.
That fits "never send media or text anywhere the user did not choose". The app does not open
any network connection for this. Update `docs/security.md` §20 to say so.

## How it will be checked

- Unit tests as listed above (mock method channel).
- `dart format .`, `flutter analyze` (zero issues), `flutter test` (all pass).
- On a device (dev flavor), in English and in Malayalam app language:
  - Share all text to a notes app and to a messenger. Malayalam letters arrive intact.
  - Select one line, share, and check only that line arrives.
  - The bottom bar does not overflow on a narrow phone.
