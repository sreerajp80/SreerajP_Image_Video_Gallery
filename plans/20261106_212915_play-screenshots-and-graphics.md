## 1. The issue

The Play listing needs a 512 × 512 icon, a 1024 × 500 feature graphic and 2–8 phone screenshots.
None exist. The emulator is running, but:

- the app is not installed on it,
- it has no photos (DCIM and Pictures are empty),
- its screen is 1344 × 2992. That is taller than 2 : 1, and Play refuses screenshots whose long
  side is more than twice the short side.

The owner chose made-up pictures, generated by a script, for the sample library.

## 2. The fix

### 2.1 Sample library (made-up pictures only)

- A Python script (Pillow, in the session's scratch folder, not in the repository) draws about
  40 simple scenes: sky, sun, hills, sea, trees, city shapes, in different colours.
- Each gets an EXIF "date taken" spread over 2022–2026. A few are dated 6 November of earlier
  years, so the "On This Day" banner shows. No GPS, no camera serial, no faces, no names.
- One picture of printed text (for the OCR screen) and one with a code-like pattern are added.
- No videos: there is no video tool on this machine to make one. The screenshots will not show
  a video badge. The owner can add a short video later if wanted.
- The files are pushed to the emulator's `DCIM/Camera` and a second folder (`Pictures/Trips`), and
  the media scanner is run.

### 2.2 Emulator setup (undone at the end)

- Install the existing prod release APK for x86_64 (`in.sreerajp.imgvidgal`, version checked
  before install).
- Set the screen to 1080 × 1920 for the captures (`adb shell wm size`). Reset to the real size at
  the end.
- Turn on Android's status-bar demo mode (fixed clock, full battery, no notifications). Turn it
  off at the end.

### 2.4 Store icon

The launcher icon is a vector XML file. A small script turns
`ic_launcher_background.xml` + `ic_launcher_foreground.xml` into an SVG, and the in-app browser
draws it at 512 × 512 as a full square. If the vector uses something the script cannot convert,
fall back to Android Studio's Image Asset tool (owner does it).

### 2.5 Feature graphic

1024 × 500, no transparency: the icon, the app name and a short line ("Your photos stay on your
phone"), with one screenshot on the right. Drawn in the in-app browser on a canvas and saved as PNG.
English only; no claims beyond the listing.

## 4. Security impact

None on the app. Only made-up pictures go into the emulator and the images. Status-bar demo mode
hides the emulator's real notifications. The committed images must show no device name, IP
address or real data. The transfer pairing screen shows the emulator's local IP inside the code
and maybe as text; that is an emulator-only address (`10.0.2.x`), but I will blur any visible
address before committing.
