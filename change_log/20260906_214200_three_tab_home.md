# Three-Tab Home Screen with Unified Functionality

**Plan:** `plans/20260906_214200_three_tab_home.md`

## What Changed

### New Files
- `lib/screens/home/home_shell_screen.dart` — Top-level scaffold with a Material 3 `NavigationBar` providing three tabs: Timeline, Folders, Albums. Centralizes permission handling.
- `lib/screens/home/folders_tab.dart` — Folders tab showing a grid of device folders with cover thumbnails. Tapping opens the folder media screen.
- `lib/screens/home/albums_tab.dart` — Albums tab showing user-made albums and smart albums (formerly the `/albums` screen, minus the Folders section). Keeps the FAB for creating albums and the long-press menu for rename/pin/delete.

### Modified Files
- `lib/screens/timeline/timeline_screen.dart` — Removed the Albums button from the app bar (albums are now a tab). The screen still has its own permission handling as a fallback, but the parent shell handles it first.
- `lib/widgets/albums/album_media_grid.dart` — Added `selectable` parameter. When true, the grid supports multi-select (long-press to start, taps toggle during selection mode, tiles show check marks). Uses the same `selectionProvider` and `selectionModeProvider` as the timeline.
- `lib/screens/albums/smart_album_screen.dart` — Both `SmartAlbumScreen` and `FolderAlbumScreen` now show `SelectionAppBar` during selection and `BatchActionBar` at the bottom. `AlbumMediaGrid` is called with `selectable: true`.
- `lib/screens/albums/album_media_screen.dart` — Same selection/batch support as above. The remove-from-album long-press callback is passed but only fires when not in selection mode.
- `lib/core/routing/app_router.dart` — Root route (`/`) now renders `HomeShellScreen` instead of `TimelineScreen`. Removed unused `TimelineScreen` import. The `/albums` route still builds `AlbumsScreen` for deep-link backward compatibility.
- `lib/l10n/app_en.arb` — Added `tabTimeline`, `tabFolders`, `tabAlbums`, `foldersTitle`, `foldersEmpty`, `foldersEmptyBody`, `folderItemCount`.
