## Differences from the plan

- The Malayalam full store description says "ദൃശ്യ ഗാലറി" in its first sentence rather than
  "ദൃശ്യ" alone, so it reads as the app's name and not a person's name.
- In the Malayalam and Sanskrit default-app dialog, the name is in single quotes ('ദൃശ്യ',
  'दृश्य'), like 'Always' in the same sentence, so it stands out as the name to pick.

- **The built-in fallback app name is now in three languages.** The first test run failed two
  tests: "AboutScreen renders cleanly in ml" and "… in sa". The About screen test uses
  `AppConfig.fallback`, whose name was one English string. It now equals the English `titleApp`
  ("Drishya Gallery"), so the locale check saw an English string that has a translation shown
  under Malayalam and Sanskrit. Before, the two English names differed, so this gap was hidden.
  The fallback now uses `LocalizedText.byLocale` with ദൃശ്യ and दृश्य, the same as
  `app_config.json`. The fallback is shown only if the config file cannot be read.
